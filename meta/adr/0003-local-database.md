# ADR-0003: Локальная БД — Drift

## Контекст

Локальная БД — **источник правды для UI**: сеть наполняет БД, UI читает из БД через
reactive-стримы. Нужны: реактивные запросы, транзакции (outbox + кандидаты атомарно),
типобезопасные схемы.

## Решение

Используется **Drift** (`drift`, `drift_flutter`). Reactive `watch`-запросы питают UI;
изменения кандидатов и outbox-операции пишутся в транзакциях.

## Альтернативы

- **Isar** — Как я знаю ISAR под капотом все данные держит в оперативной памяти, из-за этого перегружение приложения.

## Последствия

  + reactive-стримы из коробки, SQL-гибкость, миграции;
  + поддержка транзакций и роллбэков
  + легковестность
  + кодоген drift_dev, схема/миграции под контролем.
